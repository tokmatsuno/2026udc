# いえネコ図鑑 / 家猫MAP — v8.1 NAGASAKI

Urban Data Challenge を見据えた、地域参加の「来られない理由」を家猫のメタファーで可視化するWebアプリです。

## そのままGitHubへ入れるファイル

```text
/
├── index.html                    # 診断・図鑑・結果カード
├── ienekomap.html                # 100匹基準猫＋診断結果のMAP
├── 家猫_データソース.csv          # 100匹の基準猫・根拠・出典
├── 家猫_データソース_100匹.xlsx    # 編集・管理用（Web実行には不要）
├── data/
│   └── results.jsonl             # 静的結果置き場（初期は空）
├── .nojekyll                     # GitHub Pages用
└── README.md
```

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの**中身を全部、リポジトリ直下**へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branch を `main`、Folder を `/ (root)` にして `Save` します。
6. 数分後に発行されるURLを開くと `index.html` が起動します。

## データ更新

アプリはリポジトリ直下の `家猫_データソース.csv` を優先して読み込みます。
猫タイプを追加・修正する場合は、CSVの列名を維持したまま行を編集してください。

100匹を超えて101匹、150匹へ増やすこともできます。診断ではCSV内の全基準猫と距離を計算し、最も近い猫を判定します。

## 現在の主な機能

- 5問診断：中間地点を選べるスライダー回答
- 8軸診断：連続値スライダー
- 100匹の基準猫
- 最も近い基準猫 TOP3 と判定根拠
- 各基準猫の出典・根拠区分・座標根拠表示
- 同じ診断座標から別個体を生成
- 結果カード画像保存 / 共有
- 家猫MAPへのシームレス遷移
- 任意の概略位置登録（緯度経度を丸めて扱う）
- 長崎版：ちゃんぽん・カステラ演出
- 大きめの顔、少し離した目のクラシック猫ビジュアル

## 注意

- 位置情報取得は GitHub Pages のHTTPS上で利用できます。利用者のブラウザ許可が必要です。
- `data/results.jsonl` は静的ファイルです。複数ユーザーの結果をリアルタイム共有する本番運用では、現在のGAS共有APIを利用してください。
- 家猫タイプは医療・心理診断ではありません。X/Yは100匹を比較するための設計座標です。
- 根拠URLや外部サービスは公開元の仕様変更によりリンク切れになる場合があります。
